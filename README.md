## Run Locally

Open `index.html` in a browser or use the Live Server extension
in Visual Studio Code.

## Deployment

The static portfolio can be hosted on GitHub Pages.

1. Create a GitHub repository.
2. Push the project files to the `main` branch.
3. Open repository Settings > Pages.
4. Choose Deploy from a branch.
5. Select `main` and the `/ (root)` folder.
6. Save and wait for the deployment to finish.
